## Doel van deze opdracht
Dit project bevat een basiswebsite als startpunt, een README template voor samenwerking, en een GitFlow branch-structuur.

## Branches en workflow
- main: stabiele versie
- develop: integratie van nieuwe features
- feature/naam: individuele taken
